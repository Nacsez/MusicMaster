What works today

          
    
            
  • Exact one-reference Matchering 2.0.6 compatibility
    • 
            
  • Native deterministic profiles from two through 32 references
    • 
            
  • Independent level and frequency influence
    • 
            
  • Limited, normalized, raw floating-point, and paired preview outputs
    • 
            
  • Audio-aware validation and explicit edge-case policies
    • 
            
  • Complete manifests, structured events, catalogs, and strict reimport
    • 
          

        

        

          
Truthful current limits

          
    
            
  • Match amount remains fixed at 100%
    • 
            
  • Loudness is Matchering loud-section RMS, not EBU R128 LUFS
    • 
            
  • Peak control is sample peak, not oversampled true peak
    • 
            
  • Dither, metadata copying, and external limiters are unavailable
    • 
            
  • Batch inputs run sequentially and retain independent results; cancellation is planned
    • 
            
  • Audio publication is not yet transactional across all outputs
    •

Privacy and recovery

          
The portal binds to localhost and serves no third-party assets. Source audio stays in place unless you explicitly choose another workflow.

          
On failure, inspect the manifest first, then the ordered event stream. Partial outputs are diagnostic artifacts, never proof of success.
